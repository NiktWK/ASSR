# Текущий статус реализации ТЗ 0.3

Это прототип компонентов, не готовый MVP. AC-01–AC-20 не приняты полностью.

## Реализовано и проверено локально

- Долговечные вопросы, маршрут до человека, FYI/ACTION_REQUIRED, контроль адресата и revision, дедупликация и отмена.
- Plan admission по digest и старшей роли; новый вопрос сбрасывает допуск.
- OpenCode HTTP adapter: создание сессии и отправка сообщения с профилем роли.
- Сохранение session_id при переходе PLAN/BUILD и перезапуске.
- Intent перед HTTP-вызовом; неопределённый результат блокирует повтор; отмена во время I/O не теряется.
- CLI для ручного интеграционного прогона и ограниченные профили пяти ролей.
- 9 unit/HTTP-contract тестов. HTTP проверен с тестовым сервером, workflow — с тестовым runtime.

## Не завершено

- Версия OpenCode не закреплена; реальный LLM-прогон не выполнен.
- Автоматическая обработка вопросов старшими агентами, plugin bridge, worker и переключение без ручных CLI-шагов.
- Авторизация субъектов, квоты и бюджет, tool gateway, reconciliation, таймауты и уточнения.
- Slurm, локальные процессы/Docker, интерфейс, полный эксперимент и отчёт.

Текущая проверка относится только к частям REQ-19–26 и AC-14/15/18/19/20. Следующий обязательный результат — реальный автоматический OpenCode-сценарий. Ручной прототип не является его заменой.

## Проверка среды 28 октября 2026

Попытка установки OpenCode 1.19.5: пакет opencode-ai завершил postinstall ошибкой выбора платформы. Прямой пакет opencode-linux-x64@1.19.5 установлен, но бинарник аварийно завершился (exit 134, Bun panic) даже при `--version`. Поэтому эта версия является проверенным кандидатом с отказом запуска в данной среде, а не принятой версией интеграции. Для live-проверки требуется совместимая среда; LLM и Slurm не проверялись.
