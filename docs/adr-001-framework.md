# ADR 001 Основа процесса

Дата: 26 октября 2026. Решение: LangGraph + SQL snapshots + MLflow; отдельный SSH/Docker runner.

RD-Agent наиболее близок к исходной идее, но технический пилот адаптации на реальном GPU в этой среде не выполнялся. Подготовленная спецификация допускала fallback на собственный процесс. Для первой реализации выбран этот вариант, чтобы контролировать идемпотентность, права и формат доказательств без изменения внешнего исследовательского цикла.

Это отклонение от порядка этапов ТЗ: временной пилот RD-Agent не объявляется проведённым. Решение обратимо: адаптер researcher/developer можно заменить после сравнения на одном и том же benchmark, при сохранении RunSpec, К1/К2, бюджета и runner. Два оркестратора одной кампании запускать нельзя.

| Компонент | Использование | Лицензия основного проекта |
|---|---|---|
| LangGraph | Маршрутизация ролей и шагов | MIT |
| MLflow | Параметры и метрики через REST | Apache 2.0 |
| RD-Agent | Кандидат для будущего сравнительного пилота | MIT |
| AIDE ML | Кандидат для разработки через дерево вариантов | MIT |
| AI Scientist v2 | Только архитектурный референс | The AI Scientist Source Code License |

Ни один из трёх исследовательских проектов не включён в исходники ASSR. Условия их лицензий не распространяются на код, который не использован; при будущей адаптации проверяется лицензия выбранного commit и транзитивных зависимостей. Проект ASSR пока не получает публичную лицензию без решения владельца репозитория.
